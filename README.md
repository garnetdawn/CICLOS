## Deploying to GitHub Pages

The GitHub Actions workflow builds the Vite app and publishes the generated `dist` folder when changes are pushed to `main`. In the repository settings, open **Settings > Pages** and set **Build and deployment > Source** to **GitHub Actions**. The project is served from `/CICLOS/`, matching this repository's GitHub Pages URL.
